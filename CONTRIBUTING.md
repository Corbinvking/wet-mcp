# Contributing

This public repository is the integration and documentation package for a proprietary hosted service. It is not an open-source implementation project and does not accept backend feature code.

Useful issues include:

- a reproducible client configuration failure;
- a manifest that no longer matches an official client schema;
- a documentation contradiction;
- an evaluation case that fails to preserve identity, freshness, units, attribution, or refusal behavior; or
- an incorrect public coverage or capability claim.

Include evidence and remove all credentials and personal data. By submitting text or configuration changes, you authorize World Event Trading to use them in this proprietary integration package; no ownership in W.E.T. marks, hosted code, or data is transferred.

Security findings must not be opened publicly. Follow [`SECURITY.md`](SECURITY.md).
