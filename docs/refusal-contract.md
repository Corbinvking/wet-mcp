# Refusal contract compatibility entry point

The maintained refusal contract is [`REFUSALS.md`](REFUSALS.md). A typed refusal is a substantive result: preserve its code, reason, required evidence, and withheld field. Do not replace a withheld value with zero, null, a prior value, or a guess.

`source_rights_pending` is the current default-deny response for six W.E.T.-sourced/derived tools under policy `mcp-source-rights/2026-09-05.phase1`. It is protocol-safe but not a useful sourced result.

The public method is [worldeventtrading.com/methodology/refusals](https://www.worldeventtrading.com/methodology/refusals).
