# Security policy

Report a suspected vulnerability privately by emailing **security@worldeventtrading.com**. Include the affected URL or component, UTC time, reproduction steps, impact, and a safe way to validate the issue.

Do not include a live secret or another person's personal data unless it is necessary to establish the finding. Never post access tokens, refresh tokens, API keys, authorization codes, session cookies, or one-time codes in a public issue.

## Testing boundaries

Do not test by degrading service, accessing another user's account, changing data you do not own, sending spam, bypassing quotas, or trading through a third-party venue. Use the keyless research surface or state created in your own W.E.T. account.

## Current posture

W.E.T. does not claim a public bug bounty, coordinated-disclosure safe harbor, SOC 2 report, ISO 27001 certification, penetration-test attestation, uptime SLA, or guaranteed response window. If that changes, the hosted [security record](https://www.worldeventtrading.com/security) and changelog will be updated.

The hosted [security page](https://www.worldeventtrading.com/security) is canonical.
